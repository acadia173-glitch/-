# 「北欧神斗士闯黄金十二宫」开工必读

本目录是本系列的**制作规范包（production bible）**。以后每一集（第三集及以后）开工前，Howard / Vivi / 云端代理**必须先完整阅读本包和 `refs/` 中的锁定静帧**，再写分镜、再调用 LibTV 或任何视频生成。目的是沿用已经锁定的设定，避免把已否决的造型、机位、对白和动作逻辑再生成一遍，浪费 LibTV / 视频账户积分。

本包是综合后的**现行规则**，不是把旧 README 原样堆在一起。若本包与早期试片说明冲突，以本包为准；若本包与用户当集新指示冲突，以用户当集书面指示为准，并在该集交付说明里记下变更。

## 开工顺序（先做这些，再生成）

1. 读完本 `README.md`，确认当前集数状态、本包有什么、没有什么。
2. 读 [`01-creative-rules.md`](01-creative-rules.md)：风格、对白、节奏、审看-不发布、禁止擅自拼接/改成片、结尾必须停在「准备前往下一宫」。
3. 读 [`02-locked-designs.md`](02-locked-designs.md)，并对照 [`refs/`](refs/README.md) 的锁定静帧与「缺陷对照」图。
4. 读 [`03-workflow-and-credits.md`](03-workflow-and-credits.md)：先短预览再出成片、LibTV 规格、命名、审片责任。
5. 用 [`04-qa-checklist.md`](04-qa-checklist.md) 作为生成前和交付前的检查表。
6. 再读本集之前各集的经验：[`05-episode-01.md`](05-episode-01.md)、[`06-episode-02.md`](06-episode-02.md)。第二集的返工代价最高，尤其不要重复那些已导致重做的错误。
7. 为**新的一集**新建项目与修订目录，不要沿用第二集的 LibTV 项目当下一集的工作树。
8. 未经用户明确要求，不要重做已定稿或现行待审成片，也不要开始生成第三集以外用户并未授权的镜头。

## 本包收录什么、不收录什么

**收录：**

- 已经立定、下一集仍应遵守的创作与技术规则。
- 人物 / 场景锁定说明，以及少量 jpg 静帧（锁定造型、正确开场机位、动作节点、以及标明「不要再当目标」的缺陷/残留图）。
- 省积分的生成与审片流程。
- 第一、二集的状态、路径和付出过代价的教训。

**不收录、也不应再拷进本包或 GitHub 仓库的：**

- 任何成片母版、源片、take、预览或其它 mp4 / 视频文件（体积过大，且母版应留在各集工作目录）。
- 账号、密码、Cookie、API 密钥、积分或登录凭证。
- 把早期已被否决的整份过程 README 原样复制进来（教训已吸收进本包）。

成片仍在原路径，本包只用相对链接指向它们，例如：

- 第一集现行剪辑：`../episode01/revision11/episode01-through-staredown-zh-sub.mp4`
- 第二集已接受成片：`../episode02/revision05-libtv/ep02-r05d-libtv.mp4`

拷贝本包到 GitHub 时，请只提交 `production-bible/` 目录内的 Markdown 与 `refs/` 静帧，不要把各集 `*.mp4` 一并推送。
